Pencil + AI：让设计稿长在代码库里

发表于2026-09-14|更新于2026-09-14|AI
|总字数:1.9k|阅读时长:6分钟|浏览量:

前言

传统流程里，设计师在 Figma"疯狂梵高"，开发者在疯狂 Vibe Coding，中间的交付充满"赛博折磨"——设计师一走查，还要再"相看两厌"一遍。

Pencil 就是为填上这条缝而生的：

设计文件就是代码库的一部分，设计画布与代码编辑器合二为一。设计的终点不再是一张精美的 JPG，而是触手可及、实时运行的生产力。

这条笔记整理 Cursor + Pencil 的完整使用方式：从环境搭建、自然语言生成设计稿，到设计转代码本地跑起来，外加踩坑实录。它和我的《Vibe Coding 范式：UI 先行》是一脉的——Pencil 把"UI 先行"推到了更前面一步：连设计稿本身都由 AI 画，而且画完直接活在 Git 里。

Pencil 是什么，不是什么

是什么嵌入 IDE 的设计插件：双向 MCP 矢量无限画布工具
不是什么不是独立的设计软件（别去官网下桌面版，会和插件冲突导致 MCP 连接失败）
文件格式.pen 专属格式，可直接存进代码仓库，Git 也能管设计
协议基于 MCP（Model Context Protocol），理论上可与 Claude Code、OpenAI Codex 等配合
模型支持目前仅支持 gpt 和 claude 两类模型

它解决的核心痛点：设计与开发无缝衔接。设计参数（颜色值、圆角、间距）在生成设计稿时就被自动提取，Agent 拿着就能直接生成代码，不用在设计工具和代码编辑器之间来回切换、手动量像素。

第一步：环境搭建（5 分钟）

  1. 安装 Cursor：去 cursor.com/cn 按系统下载安装包。首次启动选 "Skip and continue"（跳过 VS Code 插件导入），然后登录账号——不登录用不了 AI。
  2. 安装 Pencil 插件：Cmd+Shift+X（Win：Ctrl+Shift+X）打开插件市场，搜索 "Pencil"（首字母大写，避免搜到无关插件）→ Install。装完左侧边栏出现"铅笔"图标即成功；没出现就重启 Cursor。
  3. 注册 Pencil 账号：到 pencil.dev 注册并登录，插件才能工作。

⚠️ 再次强调：不要装 Pencil 的独立桌面应用。已装的话先卸载，再重装 IDE 插件，否则 MCP 连接失败。

第二步：自然语言生成设计稿

点击左侧"铅笔"图标 → "New .pen file" 新建画布。.pen 文件建议直接放在代码仓库里（比如 design/ 目录），从此设计稿和代码同呼吸、共版本。

给文件起个可识别的名字（如 home.pen），然后在 Cursor 的 New chat 里用自然语言描述页面。描述越详细，效果越好——布局结构、具体文案、颜色（连十六进制值都给上）、风格、适配端，一样别落：

发送后等 30 秒到 1 分钟，画布上会自动绘制出完整设计稿（含元素位置、颜色、字体），并自动提取关键设计参数。

提示词写不动？外包给外部 AI。 和 Vibe Coding 范式里"军师"的用法一样——把需求先丢给 ChatGPT / 豆包，让它帮你扩写成上面这种结构化提示词，再贴回 Cursor 生成，页面丰富度直接上一个台阶。

第三步：完善设计（双向编辑是灵魂）

Pencil 支持双通道修改，这是它比纯 prompt 工具好用的地方：

  • Chat 改：继续对话迭代设计，AI 会自动把需求拆成任务表，一条一条调用 pencil MCP 去执行；
  • 鼠标改：像 Figma 一样直接上手拖拽，图层、自动布局都有。

深度测评里的实操案例（Web 端实验室耗材管理系统）值得抄作业：

几个进阶玩法（全部实测可用）：

  • 从 Figma 搬运：做好的 Figma 图直接贴进画布，和 AI 生成的元素混排；
  • 全局替换：用一句指令把所有字体统一改成 PingFangSC；
  • 组件复制：把画布上的按钮复制一份到 banner 里，直接可用；
  • 做减法：删掉不满意的区域，让 AI 在剩下的基础上继续。

第四步：设计转代码

设计稿定稿后，继续在 Agent 里用自然语言指定技术栈和目录位置，让它搭出可运行的页面：

跑起来后点击右下角的本地部署链接（http://localhost:3000）预览。有前端基础的自己跑依赖和环境；不懂就直接让 AI 帮你跑。成品带交互，还有小瑕疵就继续对话迭代，后面可以直接接着连后端数据库接口——或者"发给前端小哥"。

总结

环节动作关键点
环境搭建装 Cursor → 装 Pencil 插件 → 登录 pencil.dev别装独立桌面应用
生成设计.pen 文件进仓库，Chat 里写结构化 prompt越详细越好，可让外部 AI 润色提示词
完善设计Chat 迭代 + 鼠标微调Figma 搬运、组件复制、自动布局
转成代码指定框架/目录，Agent 直接开发localhost 预览，接后端无缝衔接

这套组合适合：新手练手、快速做原型、专业开发者提效。而对我的 Vibe Coding 范式来说，它补上了"设计稿"这一环——Impeccable 直接在代码里打磨 UI，Pencil 则先在画布上把设计稿快速画出来再转代码，前者适合 App 这种重交互的长期打磨，后者适合 Web 原型的快速交付。工具随场景选，范式不变。
