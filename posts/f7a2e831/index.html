Expo 全栈质检流水线：Skills 静态审计 + agent-device 真机 Dogfood

发表于2026-11-20|更新于2026-11-20|AI前端
|总字数:1.7k|阅读时长:6分钟|浏览量:

前言

Expo / React Native 项目里，只让 AI 读仓库很难覆盖导航真跳、列表性能、同步状态等「跑起来才知道」的问题。一条实用路线是：先静态审计并修，再真机 Dogfood 验收。

你需要的不只是「多装几个插件」，而是分清：谁提供 RN 专家上下文、谁管流程纪律、谁能在模拟器/真机上动手验证。下文先说明 callstackincubator/agent-skills 与 agent-device 各自是什么，再给你一条可直接复制的 AI 口令。

callstackincubator/agent-skills 是干什么的

callstackincubator/agent-skills 是 Callstack（长期做大型 RN 商业项目的团队）开源的一套 Agent Skills：把性能、导航、测试、迁移等实战经验写成 SKILL.md 和参考文档，装进 Claude Code、Cursor、GitHub Copilot、Codex、Gemini CLI 等助手的上下文里。

它解决什么问题： 没技能时，AI 容易写过时 API、忽略启动耗时和列表性能、测试与真机 QA 只能口述。装上之后，你仍用自然语言提问（例如「查这个页面 FPS」「帮我把 RN 升到当前版本」），助手会按任务自动加载对应技能，输出更接近生产环境的建议和改法。

官方一键装全包：

只装某一个时，把 '*' 换成技能名，例如 react-native-best-practices。OpenAI Codex 可在插件市场搜索 react native 安装对应 Bundle。

三大技能包（按生命周期）

类别包含技能（节选）主要用途
构建与优化react-native-best-practices、react-navigation、react-native-tv-best-practices、create-react-native-library、upgrading-react-nativeFPS / 启动 / 内存 / 包体 / 动画；Navigation 7、安全区、弹窗；TV 焦点；建库、平滑升级 RN
测试与验证github-actions、react-native-testing、agent-device、dogfoodRNTL 单测；CI 打 iOS/Android 产物；真机/模拟器 UI 自动化、截图、日志、探索式 QA
迁移与现代化assess-react-native-migration、react-native-brownfield-migration评估是否适合迁 RN；原生应用渐进式 Brownfield 接入

注意：dogfood / agent-device 技能写在 Callstack 大包里的「测试与验证」模块中，教 AI 什么时候做探索式 QA、报告长什么样；与下一节的 CLI + 独立 skill 仓库 是配套关系，不是二选一。

和 Expo Skills、Superpowers 怎么拼

一篇「Expo 全栈质检」流水线里，常见组合如下：

组件安装分工
expo/skillsnpx skills@latest add expo/skills --skill '*'Expo / EAS 官方语境：expo-router、数据获取、升级、原生 UI 等，避免 SDK 文档漂移
callstackincubator/agent-skills见上RN 通用专家能力：性能、导航、测试、迁移；含 dogfood 流程定义
obra/superpowersnpx skills@latest add obra/superpowers过程纪律：先 invoke 技能、调试要有根因、完成前要验证
agent-device CLI + skill见上两条 npm真机/模拟器上的执行与取证

记法：Expo + Callstack 定「写什么、怎么审」；Superpowers 定「怎么做事」；agent-device 定「跑起来证明」。

环境准备（本机一次）

App 需已装进模拟器或真机（如 npx expo run:ios / npx expo run:android）。Android 部分机型若无法做无障碍快照，在开发者选项打开 USB 安装后重试；iOS 需本机 Xcode 可用。环境细节可交给 AI 读 physical-device 相关说明排查。

小结

你做的AI 做的
装 expo / callstack / superpowers / agent-device按技能审计、修代码、Dogfood、写报告
expo run:* 把包装到设备遍历你声明的核心流程
说清页面范围与账号策略分类问题、留证、写清残余风险

callstackincubator/agent-skills 相当于给助手配了一位 Callstack 级别的 RN 顾问；配上 agent-device，顾问的话能落到模拟器和真机上。全量 Dogfood 适合发版前或大改后，日常仍以单测和静态检查为主——你把目标和边界说清楚，比亲自记 CLI 更值得。
